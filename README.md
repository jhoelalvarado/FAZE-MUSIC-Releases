# INFINYX — Descargas públicas

Repositorio de **solo descargas**: aquí se publican los APK de cada versión de INFINYX (reproductor de música local para Android).

- La propia app lo consulta para **auto-actualizarse** (Ajustes → Buscar actualización) sin cuentas ni tokens.
- Cada release incluye el APK y su **md5** en las notas para verificar la integridad.
- El código fuente es privado; este repo no contiene código.

Instalación: descarga el `INFINYX-vX.Y.Z.apk` de la última release, ábrelo y Android lo instalará/actualizará encima (misma firma ⇒ se conservan TODOS tus datos).

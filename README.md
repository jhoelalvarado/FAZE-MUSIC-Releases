# FAZE MUSIC — Descargas públicas

Repositorio de **solo descargas**: aquí se publican los APK de cada versión de FAZE MUSIC (antes INFINYX; reproductor de música local para Android).

- La propia app lo consulta para **auto-actualizarse** (Ajustes → Buscar actualización) sin cuentas ni tokens.
- Cada release incluye el APK y su **MD5** (y desde v0.77.0 también **SHA-256**) en las notas para verificar la integridad.
- El código fuente es privado; este repo no contiene código.
- Los assets de releases viejas pueden llamarse `INFINYX-vX.Y.Z.apk`; desde v0.77.0 el nombre es `FAZE-MUSIC-vX.Y.Z.apk`. La app acepta cualquier `.apk` de la release.

Instalación: descarga el APK de la última release, ábrelo y Android lo instalará/actualizará encima (misma firma ⇒ se conservan TODOS tus datos).
